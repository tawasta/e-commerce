=============================
eCommerce Extra info settings
=============================

* Allow hiding/showing items in extra info
  * Hide/show reference
  * Hide/show feedback
  * Hide/show attachment
* Add order reference into the reference field by default
* Enlarge feedback textarea

Configuration
=============
\-

Usage
=====
Go to Extra info-stage and select Customize on upper left.
