=====================
Website Sale Domicile
=====================

By default is off!

* Adds domicile to website checkout form
* Switch this functionality on and off by toggling active state of view with
  External Id: website_sale_domicile._opt_website_sale_domicile_show
  (make the search show active and inactive and search for "_opt_website_sale_domicile_show")
