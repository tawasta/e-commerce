============================
eCommerce: Customer's Gender
============================

This module lets customers fill in their gender during website checkout
when their cart contains a membership product.

When the cart contains at least one product flagged as a membership
product, the checkout address step shows an extra Gender field. The
selected value is saved on the customer's contact record. If the
contact already has a gender set, it is pre-selected.

Configuration
=============
\-

Usage
=====

#. Add a membership product to the cart and proceed to checkout.
#. On the address step, fill in the Gender field.
#. Submit the address - the value is saved on the customer's contact.
