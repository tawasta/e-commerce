=============================================
eCommerce: Hide countries from eCommerce Flow
=============================================

* Manually choose countries that will be shown on eCommerce address country list

Configuration
=============

* Go to Country form in Contacts, and check the box
  "Show in eCommerce Country Selection"

Usage
=====
* Go to checkout. Only enabled countries are shown in country dropdown

Known issues / Roadmap
======================
* This is a modified of backport of res_country_website_published originally made for 17.0.
  This one does not affect My Account, only eCommerce checkout flow.
